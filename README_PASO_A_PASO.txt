SERAUTO - POLÍTICA DE PRIVACIDAD PARA GITHUB PAGES
==================================================

ANTES DE SUBIR
--------------
REEMPLAZA EN LOS DOS ARCHIVOS:

empresa@serauto.cl

por el correo real que Serauto utilizará para solicitudes de privacidad.

Ejemplo:
contacto@serauto.cl


ESTRUCTURA
----------
Serauto_Politica_Privacidad_GitHub/
│
├── index.html
├── assets/
│   └── serauto-logo.jpeg
└── eliminacion-datos/
    └── index.html


PASO A PASO EN GITHUB
---------------------

1. Entra a:
   https://github.com/

2. Inicia sesión.

3. Pulsa:
   New repository

4. Nombre recomendado:
   serauto-privacidad

5. Selecciona:
   Public

6. Pulsa:
   Create repository

7. Dentro del repositorio pulsa:
   Add file > Upload files

8. Arrastra TODO el contenido de esta carpeta:
   - index.html
   - assets
   - eliminacion-datos

9. Baja y pulsa:
   Commit changes

10. En el repositorio entra a:
    Settings

11. En el menú izquierdo entra a:
    Pages

12. En:
    Build and deployment
    Source

    selecciona:
    Deploy from a branch

13. En Branch selecciona:
    main

    carpeta:
    / (root)

14. Pulsa:
    Save

15. Espera unos minutos.

16. GitHub te dará una URL parecida a:

    https://TU-USUARIO.github.io/serauto-privacidad/

17. Abre esa URL y comprueba que cargue.

18. Comprueba también:

    https://TU-USUARIO.github.io/serauto-privacidad/eliminacion-datos/


PONER LA URL EN META
--------------------

En Meta Developers:

Serauto prueba
> Configuración de la app
> Básica

Busca:
URL de la política de privacidad

Pega:

https://TU-USUARIO.github.io/serauto-privacidad/

Guarda los cambios.


SI META PIDE ELIMINACIÓN DE DATOS
---------------------------------

Usa:

https://TU-USUARIO.github.io/serauto-privacidad/eliminacion-datos/


IMPORTANTE
----------
La URL debe:
- ser pública;
- usar HTTPS;
- abrir sin iniciar sesión;
- contener datos de contacto reales;
- describir el uso de WhatsApp y los datos procesados.

Esta plantilla es una base funcional para publicación técnica y requisitos de
Meta. Antes de utilizarla comercialmente de forma definitiva, Serauto debería
revisar que refleje exactamente sus prácticas reales de tratamiento de datos.
